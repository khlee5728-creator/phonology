§6.1 Introduction — What is a Syllable?

Syllable (σ)

A unit of speech typically organized around a single vowel (or sonorous peak). Often described as a "beat" or "pulse" of speech.

Intuition test

Tap your hand once per syllable:

strength1 syllable
phonologypho·nol·o·gy = 4
articulatoryar·tic·u·la·to·ry = 6

Why do we need this concept?

  • Aspiration: applies at syllable-initial position
  • Stress: assigned to syllables, not segments
  • Flapping: occurs between syllable-boundary vowels
  • Phonotactics: constraints apply within syllables
음절의 정의는 직관적이지만 언어학적으로 정확히 정의하기 어렵습니다. "박자(tap)" 테스트가 가장 직관적인 방법입니다. "strength"가 한 음절임에도 자음군이 매우 복잡하다는 점을 강조하세요. 이것은 언어마다 허용되는 음절 구조가 다름을 보여줍니다.

§6.1 Introduction — Onset, Rhyme, Nucleus, Coda

         σ
        / \
     Onset  Rhyme
             /  \
           Nuc  Coda
            |    |
            V   (C)

Onset: consonant(s) before nucleus

Nucleus: vowel (obligatory)

Coda: consonant(s) after nucleus (optional)

Rhyme = Nucleus + Coda

Examples

WordOnsetNucleusCoda
at /æt/Ø/æ//t/
cat /kæt//k//æ//t/
see /siː//s//iː/Ø
string /stɹ̣ɪŋ//stɹ̣//ɪ//ŋ/
strengths/stɹ̣//ɛ//ŋkθs/

"strengths" has 4 coda consonants!

음절 구조 트리는 음절을 계층적으로 표시합니다. Onset과 Nucleus는 σ의 직접 자식이 아닙니다 — Nucleus와 Coda가 Rhyme 아래 묶인다는 점이 중요합니다. Rhyme이 별도로 묶이는 증거: 시(poetry)의 운(rhyme)은 모음부터 끝까지의 부분이 같은 것입니다.

§6.1 Introduction — Open vs. Closed Syllables

Open Syllable (CV)

Ends with a vowel — no coda.

go /goʊ/
see /siː/
ba-na-na /bə.ˈnæ.nə/all 3 syllables open!
Closed Syllable (CVC)

Ends with a consonant — has a coda.

cat /kæt/
band /bænd/
strengths /stɹ̣ɛŋkθs/
Recall from Week 9: Lax vowels (/ɪ ɛ æ ʊ ʌ/) can only occur in closed syllables. Tense vowels can occur in both open and closed syllables.
개음절(open syllable)과 폐음절(closed syllable)의 구분은 강세 규칙과 이완 모음 분포 제약에 직접 연결됩니다. "banana"의 세 음절이 모두 개음절이라는 점을 주목하게 하세요.

§6.1 Introduction — Skeletal Tier (X-slots)

Skeletal Tier

Timing units represented as X slots. Each X = one timing position. Allows formal representation of long vs. short segments.

Long vs. short vowels

σ               σ
|               |  \
X  X  X         X   X   X
|  |  |         |   |   |
p  ɪ  t         b   iː  t
"pit"           "beat" (long V = 2 X)

Long vowels and diphthongs (/aɪ/) occupy 2 X-slots; short vowels occupy 1.

Affricates: phonetically complex, phonologically simple

σ                  σ
|  \               |  \
X   X  X  X        X   X  X  X  X
|   |  |  |        |   |  |  |  |
tʃ  ɑ  ɹ  t        d   ɹ  ɛ  n  tʃ
"chart"            "drench"

Affricates [tʃ], [dʒ] = 1 X-slot (despite two-segment articulation).

X-tier(골격층)는 분절음을 시간 단위로 표시하는 방법입니다. 장모음이 두 개의 X-slot을 차지한다는 것은 음절 무게(syllable weight) 계산에 중요합니다. 이중모음도 두 X-slot을 차지합니다.

§6.2 Number of Syllables — When Counting Disagrees

Speakers usually agree, but some words show disagreement

Most words give unanimous counts: consumptiveness, docility, divinatory (4 syllables); cosmographical (5). Disagreement is limited to certain groups.

Sources of disagreement
  • Dialectal differences
    military [mɪ.lə.tɛ.ɹi] (AmE, 4) vs. [mɪ.lə.tɹi] (BrE, 3)
  • Schwa deletion
    veteran [vɛ.tə.ɹən] (3) or [vɛ.tɹən] (2)
    management 3 or 2
  • Sonorant consonants
    chasm, fire, real, male — 1 or 2?
Yavaš's solution: peaks of sonority

Define syllables based on sonority peaks:

Number of syllables
= number of sonority peaks

→ Each sonority peak in a word corresponds to one syllable. Sonority becomes the central concept in the next section (§6.3).

교재 §6.2. 화자들은 보통 음절 수에 동의하지만 (consumptiveness, docility, divinatory 4음절; cosmographical 5음절), 일부 단어는 의견이 갈림: (1) 방언 차이 — military (AmE 4 vs BrE 3); (2) Schwa 삭제 — veteran (3 vs 2), management (3 vs 2); (3) Sonorant consonants의 모호성 — chasm, fire, real, male이 1음절인지 2음절인지. Yavaš의 해법: 음절 = sonority peak 수. 이 정의가 다음 섹션 §6.3 Sonority로 자연스럽게 이어짐. 학생들에게 fire/hire를 천천히 발음시키며 [faɪɚ] 한 음절로 들리는지 [faɪ.ɚ] 두 음절로 들리는지 직관 테스트 권장.

§6.3 Sonority — Hierarchy

Sonority

The relative acoustic openness of a sound. More open = higher sonority. Basis for syllable structure universals.

Syllabic consonants — when there is no vowel

When a syllable has no vowel, the most sonorous consonant becomes the syllable peak (= syllabic consonant). Confined to unstressed syllables.

Examples: pickle [pɪ.kl̩] (lateral [l] is peak), sudden [sʌ.dn̩] (nasal [n] is peak)

공명도 수치 척도는 Hogg & McCully (1987)의 10점 척도로, 교재 Yavaş(2020) p.158에 제시된 것입니다. 수치가 높을수록 공명도가 높습니다. 이 척도를 이용해 'play'의 두음 /pl/ 을 계산하면: /p/(1) → /l/(6) → /eɪ/(9) 로 계속 상승합니다(SSP 만족). 반면 */lp/ 는 /l/(6) → /p/(1) 로 하강하므로 유효한 두음이 아닙니다.

§6.4 Syllabification — Maximal Onset Principle

Maximal Onset Principle (MOP)

When a consonant is between two vowels, assign it to the onset of the following syllable rather than the coda of the preceding one — subject to phonotactic well-formedness.

MOP applies

extra/ɛk.strə/ not */ɛks.trə/: /str/ is a valid onset ✓
phonology/fə.ˈnɑ.lə.dʒi/: each medial C goes to next onset

MOP blocked by phonotactics

winter/wɪn.tɚ/: /nt/ is not a valid English onset → /n/ stays as coda
monster/mɑn.stɚ/: /nst/ invalid onset → /n/ goes to coda
Same [mp] sequence, different syllabification

complain [kəm.plen]: /pl/ is a valid onset → [p] joins next syllable's onset.

temptation [tɛmp.te.ʃən]: /pt/ is not a valid onset → [p] stays as part of the first syllable's coda.

MOP는 "두음을 최대화하라"는 원칙입니다. 하지만 음소배열론 규칙을 위반하면 안 됩니다. "winter"에서 /nt/가 영어의 허용 두음이 아니기 때문에 /n/은 앞 음절의 코다(coda)로 남습니다. 형태소 경계도 MOP를 차단할 수 있습니다(다음 주 12주차 내용). 교재 §6.4 핵심 예시: complain vs temptation — 같은 [mp] 시퀀스이지만 [pl]은 valid onset이라 complain은 [kəm.plen]으로 syllabify, [pt]는 invalid onset이라 temptation은 [tɛmp.te.ʃən]으로 [mp] 모두 coda에 남음. MOP가 phonotactic 제약과 어떻게 상호작용하는지 보여주는 best 예시.

Practice: Syllabification

MOP Step-by-Step: publicity
[p ʌ b l ɪ s ə t i] — 4 syllables
Step 1: identify nuclei → /ʌ/ /ɪ/ /ə/ /i/
Step 2 (from right): /ti/ = valid onset ✓ → ...tì
Step 3: /sə/ = valid ✓ → ...sə.ti
Step 4: /bl/ before /ɪ/ = valid onset ✓ → ...blɪ.sə.ti
Result: [pʌb.lɪ.sə.ti]

Summary

Key Concepts — Week 11

  • Syllable structure: σ → Onset + Rhyme (Nucleus + Coda)
  • Open syllable: no coda (CV); Closed syllable: has coda (CVC)
  • Skeletal Tier: X-slots represent timing; long V = 2 slots
  • Sonority Hierarchy: Stops < Fricatives < Nasals < Liquids < Glides < Vowels
  • MOP: maximize onset, subject to phonotactic legality
