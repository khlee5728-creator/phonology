§6.1 Introduction — What is a Syllable?

Syllable (σ)

A unit of speech typically organized around a single vowel (or sonorous peak). Often described as a "beat" or "pulse" of speech.

"Despite the difficulties involved in providing a definition, the syllable is universally recognized as a fundamental unit of speech." — Yavaş (2020, p. 153)

Intuition test

Tap your hand once per syllable:

strength1 syllable [stɹ̣ɛŋkθ]
phonologypho·no·lo·gy = 4 [fə.ˈnɑ.lə.dʒi]
articulatoryar·ti·cu·la·to·ry = 6 [ɑɹ̣.ˈtɪ.kjə.lə.ˌtɔ.ɹ̣i]

Why do we need this concept?

  • Aspiration: applies at syllable-initial position
  • Stress: assigned to syllables, not segments
  • Flapping: occurs between syllable-boundary vowels
  • Phonotactics: constraints apply within syllables
음절의 정의는 직관적이지만 언어학적으로 정확히 정의하기 어렵습니다. "박자(tap)" 테스트가 가장 직관적인 방법입니다. strength /stɹ̣ɛŋkθ/는 한 음절임에도 onset /stɹ̣/ (3C)와 coda /ŋkθ/ (3C)가 매우 복잡 — 영어가 허용하는 자음군의 극단적 예. 음절 분리는 MOP 기반(phonological syllabification): phonology = pho·no·lo·gy (l이 σ3의 onset으로), articulatory = ar·ti·cu·la·to·ry (k가 σ3의 onset /kj/로, r이 σ6의 onset으로). 이는 §6.4에서 본격적으로 다룰 MOP의 결과이며, 사전 hyphenation과는 다를 수 있음을 학생들에게 미리 안내하면 좋습니다.

§6.1 Introduction — Onset, Rhyme, Nucleus, Coda

         σ
        / \
     Onset  Rhyme
             /  \
           Nuc  Coda
            |    |
            V   (C)

Onset: consonant(s) before nucleus

Nucleus: vowel (obligatory)

Coda: consonant(s) after nucleus (optional)

Rhyme = Nucleus + Coda

Examples

WordOnsetNucleusCoda
at /æt/Ø/æ//t/
cat /kæt//k//æ//t/
see /siː//s//iː/Ø
string /stɹ̣ɪŋ//stɹ̣//ɪ//ŋ/
strengths /stɹ̣ɛŋ(k)θs//stɹ̣//ɛ//ŋ(k)θs/

strengths has up to 4 coda consonants (with /k/-epenthesis)!

음절 구조 트리는 음절을 계층적으로 표시합니다. Onset과 Nucleus는 σ의 직접 자식이 아닙니다 — Nucleus와 Coda가 Rhyme 아래 묶인다는 점이 중요합니다. Rhyme이 별도로 묶이는 증거: 시(poetry)의 운(rhyme)은 모음부터 끝까지의 부분이 같은 것입니다.

§6.1 Introduction — Consonant Phonotactic Restrictions

Positional restrictions on consonants

Onsets and codas may be empty or filled with consonant(s), but certain consonants are restricted to a single position — a first glimpse of phonotactics (§6.5).

Onset-only consonants
  • /h/ — only word-initial / syllable-initial
    ✓ hat, ahead   ✗ *bah(/bæh/), *oh(/oʊh/)
  • /j/, /w/ — glides, primarily onset
    ✓ yes /jɛs/, wet /wɛt/   ✗ syllable-final */-j/, */-w/ (analyzed as part of diphthong)
  • /ʒ/ — rarely word-initial
    Mostly loanwords: genre, Zsa Zsa; typically word-medial: vision
Coda-only consonants
  • /ŋ/ — never word/syllable-initial
    ✓ sing /sɪŋ/, finger /fɪŋgɚ/   ✗ *ngat (illegal English onset)
  • Cross-linguistic note: Vietnamese, Cantonese etc. allow /ŋ/ in onset (e.g., Vietnamese nguyễn).
Key point: Which consonants may occur in which position is a language-specific phonotactic constraint — a core part of syllable structure.

→ Consonant cluster legality and sequencing constraints are treated fully in §6.5 Phonotactics (SSP, MOP).

§6.1에서는 음절 구조의 기본 골격(O, R, N, C)을 소개한 뒤, 자음의 위치적 제약(positional restrictions)을 간단히 언급합니다. /h/와 /ŋ/의 보충적 분포(complementary distribution by position)는 영어 음운론의 대표적인 phonotactic fact이며, 이는 §6.5에서 SSP·MOP과 함께 자음군 phonotactics로 이어집니다. 학생들이 cross-linguistic 차이(예: 베트남어 /ŋ/ onset)를 인식하도록 강조하세요.

§6.1 Introduction — Skeletal Tier (X-slots)

Skeletal Tier

Timing units represented as X slots. Each X = one timing position. Allows formal representation of long vs. short segments.

Syllable structure with X-tier — textbook examples

       σ        σ         σ                     σ
      / \     /   \      / \                /        \
     O   R    O   R     O   R              O          R
    /\   |    |  /  \   |   /\             /  \   /     \
   X  X  N    |  N  C   |  N  C           X  X   N     C
   |  | /\    | / \ |   |  |  /\          |  |  /  \  /  \
   |  | X X   X X X X   X  X X  X         |  |  X  X  X  X
   |  |  \/   | | | |   |  | |  |         |  |  |  |  |  |
   b  l  u    s a ɪ d   w  ɪ n  d         g  ɹ̣  a  ʊ  n  d

   "blue"     "side"    "wind"             "ground"
   long V     diphth.   short V            all branches

Long V (/u/ in blue) & diphthongs (/aɪ/ in side, /aʊ/ in ground) = 2 X-slots (branching N); short V (/ɪ/ in wind) = 1 X-slot — basis for syllable-weight computation (§6.7).

X-tier(골격층)는 분절음을 시간 단위로 표시하는 방법입니다. 교재 p. 155 예시: blue (장모음 /u/, branching N), wind (단모음 /ɪ/, branching C), ground (이중모음 /aʊ/, branching O+N+C 모두). 장모음과 이중모음 모두 2 X-slot을 차지하며, 이는 음절 무게(syllable weight, §6.7) 계산에 중요합니다.

§6.1 Introduction — Affricates & the X-tier

Affricates: phonetically complex, phonologically simple

Affricates [tʃ], [dʒ] have two phonetic components (stop + fricative) but occupy 1 X-slot — they pattern as single segments in syllable structure.

       σ                                 σ
      / \                               / \
     O   R                             O    R
     |   /\                            /\   /\
     |  N  C                          X X  N  C
     |  |  /\                         | |  |  /\
     X  X X  X                        | |  X X  X
     |  | |  |                        | |  | |  |
     tʃ ɑ ɹ̣  t                        d ɹ̣  ɛ n  tʃ

  "chart" — affricate onset           "drench" — affricate coda
  (O = 1 X; tʃ occupies single X)     (C branches: n + tʃ; tʃ = 1 X)

Compare: a regular cluster like /dr/ = 2 X-slots (branching onset), but affricate [tʃ] = 1 X-slot — treated as a single segment. → §6.5 (Phonotactics) treats cluster legality in detail.

파찰음(affricate)은 음성적으로는 정지(stop)와 마찰(fricative) 두 요소가 결합되어 있지만, 음운론적으로는 단일 분절음으로 취급되어 X-tier에서 1 X-slot을 차지합니다. 이는 자음군(consonant cluster)이 2 X-slot을 차지하는 것과 대조됩니다. 영어 단음절어에서 chart의 onset과 drench의 coda 둘 다 단일 X-slot에 매핑됩니다.

§6.1 Introduction — Open vs. Closed Syllables (review)

Open Syllable (CV)

Ends with a vowel — no coda.

go /goʊ/
see /siː/
ba-na-na /bə.ˈnæ.nə/all 3 syllables open!
Closed Syllable (CVC)

Ends with a consonant — has a coda.

cat /kæt/
band /bænd/
strengths /stɹ̣ɛŋ(k)θs/

← Recall from Week 9: Lax vowels (/ɪ ɛ æ ʊ ʌ/) can only occur in closed syllables. Tense vowels can occur in both open and closed syllables.

→ Preview §7.2: open vs. closed distinction is critical for English stress assignment (heavy/light syllables).

교재 §6.1 본문에서는 "open/closed syllable" 용어를 명시적으로 사용하지 않지만, 음절 내부 구조 (R = N + (C))에 따라 자연스럽게 도출되는 분류입니다. Week 9 (모음)과 Week 13 (§7.2 stress) 사이의 다리 역할을 하는 supplementary 슬라이드. "banana"의 세 음절이 모두 개음절이라는 점을 주목하게 하세요.

§6.2 Number of Syllables — When Counting Disagrees

Speakers usually agree, but some words show disagreement

Most words give unanimous counts: consumptiveness, docility, divinatory (4 syllables); cosmographical (5). Disagreement is limited to certain groups.

Sources of disagreement
  • Dialectal differences
    military [mɪ.lə.tɛ.ɹ̣i] (AmE, 4) vs. [mɪ.lə.tɹ̣i] (BrE, 3)
  • Schwa deletion
    veteran [vɛ.tə.ɹ̣ən] (3) or [vɛ.tɹ̣ən] (2)
    management 3 or 2
  • Sonorant consonants
    chasm, fire, real, male — 1 or 2?
Yavaš's solution: peaks of sonority

Define syllables based on sonority peaks:

Number of syllables
= number of sonority peaks

→ Each sonority peak in a word corresponds to one syllable. Sonority becomes the central concept in the next section (§6.3).

교재 §6.2. 화자들은 보통 음절 수에 동의하지만 (consumptiveness, docility, divinatory 4음절; cosmographical 5음절), 일부 단어는 의견이 갈림: (1) 방언 차이 — military (AmE 4 vs BrE 3); (2) Schwa 삭제 — veteran (3 vs 2), management (3 vs 2); (3) Sonorant consonants의 모호성 — chasm, fire, real, male이 1음절인지 2음절인지. Yavaš의 해법: 음절 = sonority peak 수. 이 정의가 다음 섹션 §6.3 Sonority로 자연스럽게 이어짐. 학생들에게 fire/hire를 천천히 발음시키며 [faɪɚ] 한 음절로 들리는지 [faɪ.ɚ] 두 음절로 들리는지 직관 테스트 권장.

§6.3 Sonority — Hierarchy

Sonority

The relative acoustic openness of a sound. More open = higher sonority. Basis for syllable structure universals.

공명도 수치 척도는 Hogg & McCully (1987)의 10점 척도로, 교재 Yavaş(2020) p.158에 제시된 것입니다. 수치가 높을수록 공명도가 높습니다. 이 척도를 이용해 'play'의 두음 /pl/ 을 계산하면: /p/(1) → /l/(6) → /eɪ/(9) 로 계속 상승합니다(SSP 만족). 반면 */lp/ 는 /l/(6) → /p/(1) 로 하강하므로 유효한 두음이 아닙니다. Syllabic consonant(자음 음절)은 다음 슬라이드(§6.3 Peaks & Profiles)에서 pickle, sudden 예시와 함께 다룹니다.

§6.3 Sonority — Peaks & Profiles

Sonority profile = sonority value plotted across segments. Each peak = one syllable nucleus → number of syllables = number of peaks.

publicity /pʌ.blɪ.sə.ti/ — 4 syllables

4 peaks (ʌ, ɪ, ə, i) = 4 syllables

condemnation /ˌkɑn.dəm.ˈneɪ.ʃən/ — 4 syllables

4 peaks (ɑ, ə, eɪ, ə) = 4 syllables

Syllabic consonants — when there is no vowel: the most sonorous consonant becomes the peak (= syllabic consonant, e.g., [l̩], [n̩]). Confined to unstressed syllables.

pickle /pɪ.kl̩/ — 2 syllables (peak = syllabic l̩)

Lateral [l̩] is the 2nd peak — no vowel.

sudden /sʌ.dn̩/ — 2 syllables (peak = syllabic n̩)

Nasal [n̩] is the 2nd peak — no vowel.

교재 Yavaš (2020) §6.3 pp. 158–160의 sonority profile 시각화. publicity /pʌ.blɪ.sə.ti/와 condemnation /ˌkɑn.dəm.ˈneɪ.ʃən/은 각각 4개의 vowel peak를 보여주며, 각 peak가 syllable nucleus에 해당하므로 두 단어 모두 4음절. condemnation의 [mn] 시퀀스는 sonority가 동일(5)하게 평탄하지만 음절 경계는 그 사이에 위치 (m은 앞 syllable coda, n은 뒤 syllable onset). pickle [pɪ.kl̩]와 sudden [sʌ.dn̩]은 syllabic consonant 사례 — 모음 없이 가장 sonorous한 자음(l, n)이 syllable peak가 됨. 비강세 음절에서만 발생. SSP는 §6.5에서 cluster 적합성 판정에 적용됩니다.

§6.4 Syllabification — Maximal Onset Principle

Maximal Onset Principle (MOP)

When a consonant is between two vowels, assign it to the onset of the following syllable rather than the coda of the preceding one — subject to phonotactic well-formedness.

MOP Step-by-Step: publicity

[p ʌ b l ɪ s ə t i] — 4 nuclei → 4 syllables
Step 1: identify nuclei → /ʌ/ /ɪ/ /ə/ /i/
Step 2 (right → left): /ti/ = valid onset ✓ → ...ti
Step 3: /sə/ = valid ✓ → ...sə.ti
Step 4: /bl/ before /ɪ/ = valid onset ✓ → ...blɪ.sə.ti
Result: [pʌ.blɪ.sə.ti]

→ Apply MOP right to left, maximizing each onset subject to phonotactic legality. Next slide: examples where MOP applies vs. is blocked.

MOP는 "두음을 최대화하라"는 원칙입니다. 단계별 적용: (1) 핵 확인, (2) 오른쪽에서 시작해 음소배열론 적합성을 확인하며 왼쪽으로 자음 분배. publicity의 경우 [pʌ.blɪ.sə.ti]로 분음절. 학생들에게 가능한 onset cluster (str, bl 등)를 사전 검토하게 하면 적용이 수월해집니다.

§6.4 Syllabification — MOP Applies vs. Blocked

Recall: MOP assigns medial Cs to the next onset only if the resulting cluster is a phonotactically legal onset. Otherwise, the C stays as coda of the preceding syllable.

MOP applies ✓

extra/ɛk.stɹ̣ə/ not */ɛks.tɹ̣ə/: /stɹ̣/ is a valid onset ✓
phonology/fə.ˈnɑ.lə.dʒi/: each medial C → next onset

MOP blocked ✗

winter/wɪn.tɚ/: /nt/ is not a valid English onset → /n/ stays coda
monster/mɑn.stɚ/: /nst/ invalid onset → /n/ goes coda
Same [mp] sequence, different syllabification

complain [kəm.plen]: /pl/ is a valid onset → [p] joins the next syllable's onset.

temptation [tɛmp.te.ʃən]: /pt/ is not a valid onset → [p] stays as part of the first syllable's coda.

MOP가 음소배열론 제약과 어떻게 상호작용하는지 보여주는 핵심 예시. winter의 /nt/는 영어의 허용 두음이 아니므로 /n/은 앞 음절의 coda로 남음. complain [kəm.plen] vs temptation [tɛmp.te.ʃən] — 같은 [mp] 시퀀스이지만 후속 자음 호환성에 따라 분음절이 달라짐. 형태소 경계도 MOP를 차단할 수 있음 (다음 주 12주차).
