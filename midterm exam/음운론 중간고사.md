시험 범위: 교재 Applied English Phonology Ch.1 ~ Ch. 3
시험 시간: 약 1시간 (시험 시간 고려해서 문항 수 설정 필요)
주요 사용 언어: 영어, (필요시 한국어 지시문 사용가능)
문제 유형: 객관식, O/X, 단답형 주관식, 빈칸 채우기  
요구 사항
1) 복수 답안이나 문제 오류가 생기지 않도록 주의 
2) 음운론 주요 규칙, 용어, 개념을 물어보는 단답형 주관식 
3) 빈칸 채우기 문제는 교재 본문 문장 활용
4) 교재 나 강의자료에 있는 도표, 이미지 활용해도 좋음
5) 교재에 있는 Exercise 문제를 일부 그대로 가져와서 시험 문제에 포함 (전체 시험 문항 비율의 10%를 넘지 않도록)
6) 교재나 강의자료 밖에서 문제가 출제되지 않도록 주의
7) 교재에서 소개 되고 있는 사레, 예시, 방언 연구 등을 소개하고 해당하는 음운론 규칙이나 현상을 물어보는 문제 출제 가능 
8) Phoneme("/" 사용)과 Allophone("[]"사용) 표기 규칙을 구별하여 학생들이 답안을 작성할 수 있도록 가이드 및 문제 출제 
9) 시험지 내 발음기호 표시 오류 없도록 
포맷: HTML 파일로 생성, pdf 다운로드 기능 추가 (실제는 pdf 파일을 출력하여 학생들에게 배포 에정)
유형: 학생용, 강사용(모범 답안 포함)으로 두가지 버전으로 각각 생성
